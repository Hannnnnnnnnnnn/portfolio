Game Interface Design

God of War: Console-to-Mobile Interface System

Role: UX/UI Designer · Self-directed project

Duration: July 2022 (2 weeks)

Tools: Figma, Photoshop, Illustrator

Project Overview

Console interfaces are built for a controller and a screen several feet away. Ported directly to a phone, they fail in predictable ways — targets too small to hit, type too fine to read, information too dense to parse at arm's length. I rebuilt the God of War armour and inventory system for mobile, treating the port as an interface problem rather than a resizing exercise.
